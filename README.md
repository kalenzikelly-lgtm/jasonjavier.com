# JasonJavier.com

A personal study website. Open `index.html` or visit the GitHub Pages URL.

## What's inside
- **Welcome page** — live clock & date, a Bible scripture and a motivational quote (new one every day)
- **The 8-Hour Quest** — a legendary 8-hour study day with a built-in 50/10 timer, each hour themed on a moment from great adventure books (Harry Potter, Lord of the Rings, Narnia, The Alchemist, The Odyssey)
- **Daily Bread** — a short Bible study, rotating every day of the week
- **The Explorer's Log** — a wild place on Earth and its true story, rotating daily

Built as a single static HTML file. No build step, no dependencies.
